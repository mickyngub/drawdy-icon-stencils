## 1.0.0

First public release

- UI and wireframe line icons from Lucide, grouped by Lucide's categories in one scrollable chip row, with All for every icon
- Ranked search inside the selected category or across every icon, where every word must match, 120 results at a time with Show more, `/` to search and Enter to add the first result
- Drag an icon to where you let go, or click to add it in view; repeated clicks line up in rows instead of stacking
- Size S to XL, a colour, a stroke width and an optional name label
- Icons keep their proportions and stay sharp when you zoom in
- A Recent row with the last 12 icons you placed; the options are remembered in this browser

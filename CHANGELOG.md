# Changelog

## 1.0.0

First public release

- Five tabs: Lucide icons, Simple Icons brand logos, full-colour tech and cloud logos, Fluent emoji with category chips, and round country flags
- Ranked search where every word must match, 120 results at a time with Show more, `/` to search and Enter to add the first result
- Drag an icon to where you let go, or click to add it in view; repeated clicks line up in rows instead of stacking
- Size S to XL, a colour and stroke width for single-colour icons, brand colours on or off, and an optional name label
- Icons keep their proportions and stay sharp when you zoom in
- A Recent row with the last 12 icons you placed; the tab and options are remembered in this browser
